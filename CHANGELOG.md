# Changelog

## 1.0.0 — 2026-11-11

- Based on the original macOS Notes Migrator v0.2.3 source (not a reconstructed implementation).
- Integrated `--notes-account local|icloud|ask` with manual selection guidance.
- Changed ENEX post-export behavior to reveal the file in Finder, avoiding accidental import under the wrong account.
- Preserved Flashnote ENEX timestamps and TXT folder export, Time Machine discovery, safety backup and rollback.
- Added GitHub Actions and a one-time public-repo publisher, excluded from Git and GitHub releases.

Original source before integration: experimental v0.2.3.
